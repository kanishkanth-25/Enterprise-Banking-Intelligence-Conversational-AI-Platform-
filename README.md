# Enterprise-Banking-Intelligence-Conversational-AI-Platform-
 Enterprise RAG-based banking assistant built with FastAPI, LangChain, Groq, and PostgreSQL. Features hybrid retrieval (FAISS + BM25), cross-encoder reranking, OCR document ingestion, and LangSmith observability—achieving 92% Recall@5 and 0.84 MRR@5 across 1,579 indexed chunks.
